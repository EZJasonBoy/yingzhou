# 使用说明

> 第 1–9 节以 Windows 版为例，macOS 版操作相同，Ctrl 换成 ⌘；Linux 版也相同，安装和不同之处见第 1 节末尾"Linux"；安卓手机与平板见第 10 节，电视盒子见第 11 节。

## 1. 安装与启动

两种包，内容一样，任选其一：

**安装程序**（推荐）：运行 `yingzhou-windows-x64-setup.exe`，一路"下一步"。

- 只装给当前用户，不需要管理员权限，默认装到 `C:\Users\<你>\AppData\Local\Programs\Yingzhou`，可以改。
- 装完在开始菜单里有「映舟」，安装时可选是否放桌面快捷方式。
- **升级**：直接运行新版安装程序，会装到原来的位置，订阅和记录都保留。
- **卸载**：「设置 → 应用」里找到「映舟」卸载。卸载时会问要不要一并删除订阅、观看历史、收藏和设置，默认保留。
- 安装、升级、卸载前要先关掉映舟，否则会提示你关闭。
- 安装程序没有数字签名。从网上下载的安装包第一次运行时，Windows 可能弹出"Windows 已保护你的电脑"，点"更多信息 → 仍要运行"。

**绿色包**：解压 `yingzhou-windows-x64.zip` 到任意目录（路径里最好没有特殊字符），运行 `yingzhou.exe`。要"卸载"就删掉解压目录；想清掉订阅和观看记录，再删 `C:\Users\<你>\.tvbox-next` 和 `C:\Users\<你>\AppData\Roaming\Yingzhou`。

不需要另装 Java 或播放器，引擎、Java 运行时、libmpv 都在包里。启动时界面会显示"正在启动内置引擎…"，几秒后进入首页。关闭窗口时引擎一起退出。订阅、历史和收藏由引擎保存在 `C:\Users\<你>\.tvbox-next\engine`。

### Linux

只有 x64 版，要 **Ubuntu 24.04 或更新**、**Debian 13 或更新**，或同样新的其他发行版（包是在 Ubuntu 24.04 上编出来的，用的是它的 glibc 和 libmpv；Ubuntu 22.04、Debian 12 装不上）。引擎和 Java 运行时在包里；播放器 libmpv 和 GTK 3 用系统的。

**deb 包**（Ubuntu、Debian 及其衍生版，推荐）：

```bash
sudo apt install ./yingzhou-linux-x64.deb
```

apt 会顺带装上缺的依赖（libmpv2、GTK 3 等），以及中文字体 `fonts-noto-cjk`。装好后应用菜单里有「映舟」，终端里也可以运行 `yingzhou`。程序在 `/opt/yingzhou`。**升级**：同样装新版的 deb。**卸载**：`sudo apt remove yingzhou`，不会删你的订阅和记录（见下）。

**tar.gz 包**（其他发行版，或不想用 apt）：解压到任意目录，运行里面的 `./yingzhou`。系统里要先有 GTK 3 和 libmpv（Ubuntu / Debian：`sudo apt install libgtk-3-0t64 libmpv2`；其他发行版一般是 `gtk3` 和 `mpv` 包），还要有中文字体（如 Noto Sans CJK），否则界面上的汉字是方块。想放进应用菜单就运行解压目录里的 `./install-desktop-entry.sh`（只给当前用户，不要 root；挪了目录要再运行一次；`./install-desktop-entry.sh --remove` 撤掉）。要"卸载"就撤掉菜单项、删掉解压目录。

数据放在：

| 内容 | 位置 |
|---|---|
| 订阅、历史、收藏（引擎） | `~/.tvbox-next/engine` |
| 界面设置、窗口位置 | `~/.local/share/io.github.sa1koro.yingzhou` |
| 海报缓存 | `~/.cache/io.github.sa1koro.yingzhou` |

想清干净就删掉这三个文件夹。

和 Windows 版不同的地方：

- **网页嗅探**要有 Google Chrome、Microsoft Edge 或 Chromium（发行版自带的包，或 Ubuntu 的 snap 版）。装在别处时设环境变量 `TVBOX_BROWSER` 指向浏览器程序。Flatpak 版的浏览器用不了。
- **局域网搜索**（「源 → 局域网里的引擎 → 搜索」）要系统里的 `avahi-daemon` 在运行，大多数桌面发行版默认就有；没有时会提示无法搜索，手动填地址照样能连。把本机引擎共享给局域网不需要它。
- **Python 站点**用系统的 `python3`（3.8 以上，大多数发行版自带）。「下载 Python 运行时」只有 Windows 版有。
- **窗口位置**：在 Wayland 桌面上应用不能决定窗口放在哪，下次启动只恢复大小；X11 上大小和位置都恢复。

**还没在真正的 Linux 桌面上用过。** 目前只在 GitHub 的 Ubuntu 24.04 虚拟屏幕上（Xvfb + Openbox，软件渲染）验证过：deb 能装、应用能启动并带起自己的引擎、窗口大小和位置能恢复、关窗时引擎一起退出；演示站能浏览、播放（有画面）、拖动、全屏、切字幕和音轨、显示弹幕，坏线路会自动换下一条。没验证过的：Wayland 桌面（GNOME、KDE）上的窗口和全屏、硬件解码、声音（虚拟屏幕没有声卡）、snap 版 Chromium 嗅探、真实显卡下的画面和性能、tar.gz 包在 Fedora、Arch 等其他发行版上的运行。遇到问题请到 GitHub 提 issue。

### 检查更新

「设置 → 关于」里的「更新」显示当前版本，点 **「检查更新」** 就向 GitHub 取一个很小的文件（`latest.json`，记着最新版本号、更新说明和各平台安装包的文件名），不发送任何其他信息。

- 有新版本时弹出窗口，列出这一版改了什么。点 **「下载」**：电脑上由映舟把这台电脑对应的安装包（装过的是安装程序，绿色包用户是 zip；Mac 是 DMG）存到"下载"文件夹，下完点「打开所在文件夹」，关掉映舟后运行它（升级方法见上面）；安卓手机、平板、电视盒子上会用浏览器打开对应 CPU 的 APK 下载地址，下完在通知栏点开安装。没有浏览器的电视盒子会把地址显示出来，可以抄到别的下载工具里。「发布页」在浏览器里打开这一版在 GitHub 上的页面，所有安装包都在那里。
- **自动检查更新**默认关闭（检查要访问 GitHub）。打开后每次启动约 20 秒后、之后每隔几个小时看一眼，距上次成功检查满一天才真的去取（没取到就在下一次再试）；同一个新版本只弹一次窗口，以后在「更新」里还能看到并点「查看新版本」。正在看片、在别的页面里时不弹，回到主界面再弹。
- 先直连 GitHub；直连失败时，如果「网络」里打开了 GitHub 加速代理，就经那个代理再试一次，下载也走同一条路。「更新」里会写明这次是"直连 GitHub"还是"经加速前缀 …"取到的，失败时写明每条路失败的原因（连不上、超时、HTTP 状态码、格式不对）。
- **更新用的代理**：填一个 HTTP 代理（`主机:端口`，如 `127.0.0.1:7890`，留空不用）后点"使用"，检查和下载更新都经过它；只有这两件事用它，引擎和播放都不经过它。安卓上的下载交给浏览器，浏览器不经过这个代理。
- 电视上全程可以用遥控器：更新窗口打开时焦点在「下载」上，按 ↑ 到更新说明、再按 ↑ / ↓ 翻页，返回键关闭。

## 2. 界面

窗口左侧是七个入口（窗口矮时只有当前那个显示文字）：

| 入口 | 做什么 |
|---|---|
| **首页** | 选一个站点，看推荐、按分类和筛选浏览 |
| **直播** | 电视直播和节目单 |
| **搜索** | 所有站点同时搜一个片名 |
| **我的** | 观看历史、收藏 |
| **源** | 内容从哪里来：引擎地址、订阅、已保存的订阅、站点列表、局域网里别的引擎 |
| **网盘** | AList / OpenList、WebDAV 和电脑上的文件夹里自己的视频（见第 9 节） |
| **设置** | 映舟和引擎怎么工作：外观（浅色 / 深色）、播放缓存、弹幕、网络、局域网共享、离线下载、缓存、Python、关于 |

## 3. 导入订阅

第一次打开时首页会提示"先在'源'里导入订阅"。

1. 进「源」页，在"订阅地址"里粘贴地址，点"导入"。支持 `http(s)://`、`clan://`、`file://`、带 `;pk;密钥` 后缀的加密订阅，也可以直接填本机上配置文件的路径（如 `C:\tv\my.json`）。
2. 如果是多仓订阅，会出现"选择仓库"，挑一个。条目本身又是多仓的（标着"（多仓）"），选中后会展开，它里面的条目缩进显示在下面，并自动加载其中第一个能用的。
3. 导入成功后"当前配置"显示站点、解析、直播的数量，下面列出所有站点和它们的类型。

**已保存的订阅**：导入过的订阅都列在"订阅地址"下面，最近用过的在最上面，正在用的打了勾。点一下就切换过去，不用再输地址。右边的 ⋮（触屏上长按，电视上长按 OK 或按菜单键）可以**重命名**（比如叫"家里的"，留空就显示地址）、复制地址或**删除**。删除只是从列表里去掉，不影响订阅本身；删掉正在用的那个，首页会变空，再选一个就好。

**手机输入**（电视、电脑、平板上有，手机上没有）："导入"旁边的「手机输入」会弹出一个二维码。用手机扫码（相机、微信都可以），在打开的网页里粘贴订阅地址、点「发送」，地址就填进来并立即导入，不用拿遥控器一个字母一个字母地输。要求和注意：
- 手机要和这台设备连在同一个 Wi-Fi 或路由器下。设备有几个网络地址时，二维码下面可以换一个地址再扫。
- 网页地址里带一串随机码，只显示在这块屏幕上；它只能用一次，10 分钟后失效，关掉窗口也立即失效。网页不收集别的东西，也不需要装任何应用。
- 这个网页由映舟应用自己临时提供，和引擎的「局域网共享」无关，不用打开共享。在电脑上第一次用时 Windows 防火墙可能询问是否允许映舟访问网络，选"专用网络"允许即可（不允许就只能本机用）。
- 电视上的搜索键盘、订阅重命名里也有「手机输入」，可以在手机上输中文片名。

「设置」页的「网络」里有一个 **GitHub 加速代理**开关，默认关闭：这时放在 GitHub 上的订阅和文件直接从 GitHub 获取，订阅里自带的 `gh-proxy` 之类的前缀会被去掉。直连 GitHub 很慢或打不开时再打开它：下面列出几个公共的加速代理，点一个就换成它；也可以在「自定义代理地址」里填别的，点"应用"。不知道选哪个就点 **「测速」**：引擎会直连 GitHub、再经每个代理各取一次 GitHub 上一个很小的文件（映舟仓库里的一个文本文件，不发送任何其他信息），每个代理后面显示用了多少毫秒，取不到的显示"超时"或"不可用"（把鼠标停在上面能看到原因），最上面一行是直连 GitHub 的结果——直连就很快的话不需要加速。这些代理由网友免费提供，随时可能失效，选一个测出来能用、又快的。切换后当前订阅会立即重新加载，「当前配置」下面会显示实际访问的地址。

「网络」里还有 **安全 DNS（DoH）**，默认"关闭（系统 DNS）"。有些网络会把影视站的域名解析到错误的地址（表现为站点打不开、订阅加载失败），这时可以选一个服务商（腾讯、阿里、360、Google、AdGuard、Quad9，以及当前订阅自己提供的），引擎就改用它查域名。要知道的是：打开后，引擎要访问的每个域名都会发给你选的那个服务商；订阅只能提供可选项，不能替你打开。选了之后马上生效，不用重新加载订阅；它连不上时会自动退回系统 DNS，并在下面提示一行。

订阅如果自带网络规则（`hosts` 域名重定向、`headers` 请求头、`ads` 嗅探屏蔽），「网络」底部会写出各有几条，点"查看"能看到具体内容。这些规则随订阅生效，切换订阅就换成新订阅的。

可以导入多个订阅并随时切换。当前用的订阅会记住，下次启动自动加载：引擎先用上次保存的那份订阅直接进首页，不用等下载，同时在后台获取最新的——内容有变化就自动换上，没变化就什么都不动。订阅地址暂时连不上也不影响使用，「当前配置」下面会写明"用的是某时保存的副本"和原因。想马上获取最新的订阅，点「当前配置」里的 **刷新**。

站点的首页、分类和详情也会保存一段时间（首页和分类 15 分钟，详情 1 小时），所以第二次打开是立刻显示的；过了时间再打开，先显示旧的，后台取到新的后下次就是新的。想立刻看到最新内容（比如追更新），点首页站点名右边或详情页右上角的 ⟳。海报图片保存在本机，看过的不会再下载。断网时，看过的页面和海报照样能翻，搜索和播放不行。

「设置」页「下载与数据」里的 **缓存** 一栏显示这些内容占了多少空间，可以一键清除。占用有上限（站点数据约 50 MB、海报 300 MB），旧的会自动清掉。清除后第一次启动要重新等订阅下载。播放缓存不在这里。

### Python 站点

订阅里有些站点（站点列表里标着 **PY**）和直播源是用 Python 写的，要用电脑上的 Python 3.8 或更新的版本来运行。映舟不自带 Python，「设置」页的 **Python 蜘蛛** 一栏写着现在用的是哪个：

- 电脑上已经装了 Python（python.org 的安装包、Microsoft Store、scoop、Homebrew 都行）：自动找到，什么都不用做。装在别处的，在"Python 位置"里填 `python.exe`（或它所在的文件夹）再点"应用"。
- 没有 Python（Windows）：点 **下载 Python 运行时**。确认框里写着从哪里下载（python.org）、多大（约 12 MB）、放在哪里，确认后才开始下载；它只给映舟用，不装进系统、不改环境变量，以后可以在同一处删除。macOS 请自己装 Python 3（python.org 的安装包或 Homebrew），装好后点这一栏右上角的刷新。
- **安装常用依赖**：大部分 Python 站点还要用到 `requests`、`lxml` 等第三方包。点这个按钮，映舟会用 pip 把 TVBox 的 Python 版自带的那几个包（requests、lxml、pycryptodome、beautifulsoup4、pyquery、ujson、jsonpath、cachetools）装到映舟自己的目录里，不会动你电脑上 Python 自己的环境。确认框里写着从哪里下载、装到哪里。某个站点打开时提示"缺少 Python 包 xxx"，这一栏也会列出来，旁边有"安装 xxx"按钮。
- 下载慢的话，在"镜像"里填国内的 PyPI 镜像（如 `https://mirrors.aliyun.com/pypi/simple/`）或 Python 下载镜像（如 `https://mirrors.huaweicloud.com/python/`）。下载的 Python 会按 python.org 公布的校验值检查，用镜像也一样。

Python 站点和其他站点一样浏览、搜索、播放；Python 直播源也和其他直播源一样在「直播」页里。没有 Python 时，这些站点在「源」页标着"需要 Python"，直播源标着"（需要 Python）"，打不开但不影响其他站点。

## 4. 看片

1. 「首页」选站点 → 点海报进详情页。
2. 详情页选线路和集数，点"播放"。看过的会显示"继续播放 第 N 集 mm:ss"，旁边可以"从头播放"。点 ♡ 收藏。
3. 播放页点右下角的"选集"，侧栏里可以选集和换线路。右上角显示当前线路，以及它是怎么解析出来的（经某个解析接口、网页嗅探；直链不标）。

### 线路放不了时

一部片通常有好几条线路，其中一些可能已经失效。当前线路放不了时，播放页会自己换到下一条：

- **什么算放不了**：播放地址解析失败；播放器打不开；15 秒没有画面；播到一半断开（离片尾还远就结束了）。
- **怎么换**：按线路顺序往后找有这一集的线路，到头再从第一条接着找，每条只试一次。画面中间会提示一句，例如"「线路一」解析失败，已切到「线路二」"，右上角的线路名跟着变。
- **进度不丢**：从已经播到的位置（刚打开时是历史记录里的位置）接着播，不会回到开头。
- **全部都不行**：停在你原来选的线路上，显示最后一条线路的失败原因，下面有"重试"（按同样的顺序再来一轮）和"换线路"（打开侧栏自己挑）。
- **手动选的线路不会被换走**：你在侧栏里亲手换的线路，就算放不了也只提示，不会自动跳到别的线路；换到下一集后恢复自动。手动换线路同样从当前进度接着播。

它只能发现"放不了"。线路能播但内容不对、清晰度差或只是卡顿时，还是要自己换。所有线路都失效时也不会自动去别的站点找同一部片，用「搜索」找其他站点的同名片。

找片更快的办法是「搜索」（Ctrl+F）：输入片名回车，所有可搜索的站点同时搜，结果边到边出，顶部可以按站点过滤。

### 进度条与播放缓存

很多线路是 m3u8 流，片源又慢，拖一下进度条就要重新下载、卡很久。映舟把看过的和预读的部分存下来，拖动时尽量不再去片源取：

- **拖动进度条**：按住拖的时候画面不动，进度条上方显示松手后会跳到的时间；**松手才跳，只跳一次**。鼠标悬在进度条上也会显示那一处的时间。← / → 连按会累加，连按三下就是 30 秒。
- **进度条上的浅色段**是已经缓存好的部分，跳到这些位置基本不用等（零点几秒）。
- **m3u8 视频**（大多数线路）由引擎代为下载，存在磁盘上：
  - 看过的部分一直留着，往回拖多远都不用重新下载；
  - 当前位置之后会提前下载好一段：刚开始播或刚跳转时是半分钟，连着往下看就逐步加到约三分钟；最多 4 个连接同时下，片源越慢越有用；
  - 跳到完全没缓存的位置时，那一小段拆成几块同时下载，比以前快一倍左右（取决于片源）；
  - 关掉这一集再打开、第二天接着看，缓存都还在。
- **其他直链视频**（mp4、flv、mkv 等）由播放器自己缓存到一个临时文件：这一集开着的时候，播过和预读（约五分钟）的部分都能随时跳回去；关掉这一集，临时文件就删掉。
- **占多少磁盘**：m3u8 的缓存默认最多 2 GB，放满后自动删掉最久没看的部分。在「设置」页的「播放缓存」里可以看占用、改上限、清空，或者整个关掉。直播不缓存。
- **安卓上**：缓存默认最多 1 GB，放在 App 的缓存目录里（系统空间紧张时可能清掉一部分，不影响播放）。手机剩余空间不到 500 MB 时，缓存先删掉自己最旧的内容让出空间；还不够就暂时不缓存、不预读，拖动和没有缓存时一样。「播放缓存」里会显示设备还剩多少空间。

缓存帮不上的情况：第一次跳到一个没缓存的位置，仍然要现下载，快慢取决于片源；片源本身就打不开时，缓存也没有用（见上面的"线路放不了时"）。

### 字幕与音轨

播放页右下角的「字幕」按钮（或按 C 开关字幕）打开字幕与音轨面板：

- **字幕从哪来**：视频自带的（内封字幕）、站点给的外挂字幕（带云朵图标）、你从本地加载的（带文件夹图标）。视频没有自带字幕而站点给了外挂字幕时，自动显示第一条，和 TVBox 一样。点「关闭」不显示字幕。
- **从本地文件加载**：SRT、ASS / SSA、WebVTT 之外，TTML、LRC、B 站的 JSON 字幕也行；GBK、Big5、UTF-16 等编码会自动识别（由引擎转换），不会乱码。
- **字幕时间**：字幕比画面早或晚时，每按一下 Z 提前 0.5 秒、X 延后 0.5 秒，画面中间会显示当前偏移；面板里点「归零」恢复。换一集时自动归零。
- **大小和位置**：面板里调，记在这台设备上，以后所有视频都按这个显示。ASS 字幕的字体、颜色、位置按字幕文件里写的显示（大小也跟着缩放）。
- **音轨**：视频有多条音轨（国语 / 粤语 / 英语、导演评论……）时在面板下方选，或按 A 依次切换。
- **记住选择**：给一部片选过的字幕语言和音轨记在观看历史里，下一集、下次打开都按它选；关掉了字幕，下次也是关着的。

站点给的字幕由引擎代为下载（带上站点要求的请求头），连另一台设备上的引擎时也能用。

### 弹幕

有弹幕的视频，弹幕直接飘在画面上，全屏时也一样。控制条上的气泡按钮（或按 D）开关弹幕，旁边的「弹幕」打开设置面板：

- **弹幕从哪来**：首先是站点自己给的（很多蜘蛛会给 B 站的弹幕地址）；站点没给时，如果你打开了下面说的弹幕接口，再去问接口；也可以在面板里「加载弹幕文件…」，支持 B 站 XML、弹幕 JSON、ASS（弹幕转换工具生成的）。面板里会写这一集的弹幕有多少条、来自哪里。
- **弹幕接口（默认关闭）**：在「设置」页的「弹幕」里：
  - **使用订阅提供的弹幕接口**：订阅（配置里的 `danmaku`）可能带一个按片名找弹幕的接口。打开后，每看一集，引擎都会把**片名和集数**发给这个接口的服务器——那是订阅作者选的第三方，所以默认关着，由你决定。开关下面写着接口的域名。
  - **自己的弹幕接口**：填一个你信得过的服务（弹弹play 兼容的接口地址，或者带 `{name}`、`{episode}` 的地址），站点和订阅接口都没有弹幕时才问它。不填就不用。
  - 映舟不内置任何第三方弹幕服务。
- **样式**：不透明度、字号、速度（慢 / 较慢 / 适中 / 较快 / 快）、显示区域（全屏 / 半屏 / 1/4，只占画面上方这一部分）。
- **屏蔽**：可以分别屏蔽顶部、底部、滚动弹幕；屏蔽词每行一个（或用逗号隔开），写成 `/…/` 就是正则表达式。
- 这些设置记在这台设备上。弹幕跟着播放走：暂停就停住，拖动进度条、倍速播放都对得上。

关着弹幕时不会去取弹幕，也不会问任何接口。
### 下载（离线看）

在详情页点收藏旁边的 **↓** 打开「下载」：

- 默认勾上的是"这一集"（上次看到的那集，没看过就是第一集）；可以再勾几集，或者点 **整条线路** 全选。有几条线路时先选线路。点 **下载 N 集**。
- 下载在**引擎**上进行：关掉详情页、去看别的都不影响。内置引擎随映舟退出而停下，下次打开映舟接着下，已经下好的部分不会重下；连的是 NAS 上的引擎时，关掉映舟它照样下，下完家里连着它的设备都能离线看。
- 详情页的选集按钮下面标着每一集的状态：**排队中**、**42%**（正在下）、**已暂停**、**已下载**、**失败**（鼠标停在上面显示原因）。
- **已下载的那一集照常点就是离线播放**：不用联网，马上开始，进度条拖到哪里都不用等，播放页右上角写着"离线播放（已下载）"。断网、片源失效了也能看。

「我的 → 下载」按片名分组列出所有下载：

- 正在下的显示进度、速度、已下多少；可以 **暂停** / **继续**。失败的写着原因，点 **重试** 会重新解析播放地址（地址过期是最常见的原因）。
- 下好的可以 **播放**（离线）、**导出为文件**、**删除**（引擎上的文件一起删掉）。点片名回到详情页。

**导出为文件**：把一集存成一个普通的视频文件，拷到 U 盘、用别的播放器看都行。

- m3u8 视频：所有分片按顺序拼成一个 **.ts** 文件，加密的分片先解密，常见的播放器都能播。分片是 fMP4 的拼成一个 .mp4。
- 直链视频（mp4、mkv、flv……）原样导出。
- 想要普通的 **.mp4** 需要用 ffmpeg 转换：映舟没有附带 ffmpeg，也不会替你安装。自己装了 ffmpeg 的话，`ffmpeg -i 片名.ts -c copy 片名.mp4` 几秒钟就转好（不重新编码）。
- 存到哪：引擎就在这台电脑上时，存到你的「下载」文件夹，导出后点"打开文件夹"；连的是别的设备上的引擎时，从引擎传到这台设备的「下载」文件夹。
- 个别片源把分片伪装成图片之类，拼不成标准的 .ts，导出时会提示；这样的下载在映舟里照样能离线播放。

**设置**在「设置」页的「离线下载」里：

- **同时下载**几集：默认 2 集，最多 5 集。每一集同时用 4 个连接下分片。
- **下载位置**：默认和播放缓存放在同一个文件夹里，好处是看过的部分不用再下，而且下载不占播放缓存的上限、"清空缓存"也不会删掉下载。也可以填引擎所在设备上的另一个文件夹（完整路径），只影响以后的下载，已经下好的留在原处。
- 显示已下载多少、磁盘还剩多少。磁盘只剩 500 MB 时下载会停下并提示"磁盘空间不足"；一集下了几段之后，估计剩下的放不下也会提前停下。

不能下载的：直播（点播站里其实是直播的线路也算，会提示"这是直播流，不能下载"）；要在客户端嗅探网页才能播的线路（引擎没有浏览器内核时）。

**在安卓手机、平板、电视盒子上**，App 内置的引擎一样能下载，操作相同，另外几点：

- **切到后台也接着下**：有下载在排队或进行时，通知栏里有一条「正在下载《片名》第 N 集」，带进度和速度，可以直接点 **暂停** / **取消**（同时有几集时是「全部暂停 / 全部取消」；取消会删掉没下完的部分）。第一次下载时 Android 13 及以上会问"是否允许映舟发送通知"：不允许也照样下载，只是看不到这条通知。下完、全部暂停或取消后通知自己消失。下载期间手机不会进入深度休眠，息屏也继续下。
- **存在哪**：默认在手机的内部存储里映舟自己的文件夹（`Android/data/io.github.sa1koro.yingzhou/files/downloads`），不需要存储权限。插着 SD 卡或 U 盘时，可以在「设置 → 离线下载 → 下载到」里换过去（只影响以后的下载；拔出期间那里的下载看不了）。**卸载映舟时下载会一起删掉**，想留下来就先导出。
- **导出为文件**：存进系统的「下载/映舟」文件夹（Android 10 及以上；更早的版本存在 `Android/data/io.github.sa1koro.yingzhou/files/Download`），文件管理器里能看到。导出后提示条上点 **分享** 可以发给别的 App（另一个播放器、网盘、聊天软件……）。连的是电脑或 NAS 上的引擎时，导出的文件直接从引擎传进手机的「下载/映舟」。
- 下载和播放缓存在安卓上是分开存的，看过的部分下载时还要再下一次。

### 回看

能回看的频道（订阅里给了回看规则），节目单上方会多出一排日期：「今天」「昨天」「前天」……往前最多到这个频道允许的天数。

- 已经播完的节目后面标着「回看」，点一下就从头播放这个节目；正在播的节目只回看到现在。
- 回看时频道名旁边和画面左上角都有橙色的「回看」标记，下面有进度条可以拖动，←/→ 快退 / 快进 10 秒（按住 Shift 是 60 秒），空格暂停。

- 不能回看的频道和以前一样：没有日期，节目单只是看看。
- 回看地址打不开时会提示"这个节目可能已经不能回看了"——源站一般只保留几天的录像，太早的节目往往已经删了。

- 一条线路打不开，或 15 秒没有画面，会自动换下一条；全部试过都不行才提示。
- 记住上次看的频道，下次进「直播」直接播它。
- 离开「直播」页就停止播放。
- 频道列表缓存半小时，点"刷新频道"可立即重新拉取。

## 7. 连另一台设备上的引擎

引擎可以给同一网络里的其他设备用（比如家里常开的电脑或 NAS），其他设备的客户端连它，订阅、历史、收藏、进度就都是同一份。别的设备要先**配对**一次。

**在提供引擎的电脑上**（装着映舟的那台）：

1. 「设置」页的「局域网」里打开 **局域网共享**（默认关闭）。Windows 第一次会问是否允许 Java 通过防火墙，选"专用网络"允许。
2. 下面会显示其他设备用的地址（如 `http://192.168.1.5:9978`）和一个 6 位 **配对码**。配对码 10 分钟内有效，用过一次就作废，"换一个"可以立即换。
3. 配对过的设备列在下面，显示最后一次使用的时间和地址，点"撤销"它就不能再用了，引擎发给它的播放地址也随之失效。
4. 关掉开关，引擎立即停止在网络上监听，所有设备都连不上了；再打开，已配对的设备不用重新配对。

**在要连接的设备上**：

1. 「源」页「局域网里的引擎」里点"发现局域网里的引擎"的 **搜索**，列表里点那台引擎；也可以在上面"引擎地址"里直接填地址，点"连接"。
2. 弹出「与引擎配对」，输入那台电脑上显示的配对码，点"配对"。之后这台设备会记住，下次直接连上。
3. 想断开：「局域网」里点"取消配对"，或者在提供引擎的电脑上撤销它。

**播放时视频从哪里取**（连着别的设备上的引擎时，「源 → 局域网里的引擎」里）：引擎负责找到播放地址，视频本身可以经引擎取，也可以由这台设备直接从片源取。
- **自动**（默认）：引擎在同一个局域网里（地址是 192.168.x.x、10.x.x.x 之类，或 `.local`）就经引擎取：有引擎的播放缓存，拖动进度条快，几台设备看同一部片只下载一次。引擎不在这个局域网里（比如在外面经 Tailscale 连回家，地址是 100.x.x.x 或 `*.ts.net`）就直接从片源取：视频不用先绕回家里再传过来，不占家里的上传带宽。
- **经引擎** / **直连片源**：固定用一种。
- 直连时引擎仍然负责解析地址、去掉广告，只是不再转发视频；拖动进度条时用不上引擎的缓存（这台设备自己的缓存照样有）。有的片源只认解析它的那台设备（或要用订阅里的 `hosts` 规则才能访问），直连播不了时会自动改为经引擎播放，画面下方的线路名后面会写"直连片源"或"经引擎"。
- 直播一直是直接从片源取的（只有频道的播放列表经引擎），不受这个选项影响。

**NAS / 没有界面的引擎**：用 `--lan` 启动（Docker 镜像默认如此，见第 8 节），配对码打印在引擎的日志里；在要连接的设备上打开配对窗口时，日志里会出现新的配对码。

**安卓手机、平板、电视盒子也能当引擎**：安卓设备直接运行 jar 蜘蛛，兼容性最好，家里常开的电视盒子或一台旧手机很适合给别的设备共用。做法和电脑一样：在那台设备上的映舟里「设置 → 局域网」打开 **局域网共享**，下面显示地址（如 `http://192.168.1.8:9978`）和配对码，其他设备搜索或填地址后配对。另外：

- 共享期间通知栏里一直有「局域网共享中」，写着地址和配对码（锁屏上不显示内容），点 **停止共享** 就关掉。第一次打开时 Android 13 及以上会问是否允许通知。
- 共享期间设备不会进入深度休眠、Wi-Fi 保持连接，这样息屏后其他设备也能用它，代价是更耗电；不用时关掉。电视盒子通常一直插着电，影响不大。
- 只在 Wi-Fi 或有线网络上共享，手机用移动数据时不会在移动网络上监听。换了 Wi-Fi，地址会自动更新。
- 共享开关会记住：下次打开映舟时自动接着共享。设备重启后要先打开一次映舟。
- 被安卓的省电策略强行停止（少数厂商的系统会这样）时共享也就断了；可以在系统设置里把映舟设为"不限制后台"。

说明：

- 配对码连续输错 5 次，所有设备的配对会暂停 1 分钟（再错就 2 分钟、4 分钟……最长 15 分钟），引擎换一个新码。
- 配对窗口提示"令牌无效或已被撤销"说明这台设备已被撤销或引擎的数据被清掉了，重新配对即可。
- 只在信任的网络里打开共享：配对挡住了不知道配对码的人，但传输没有加密（HTTP），同一网络里能抓包的人能看到你在看什么。
- 自动发现需要两台设备在同一个网段、路由器不拦组播；找不到时直接填地址一样能用。

## 8. 在 NAS 上运行引擎（Docker）

> **这个镜像还没有实际构建、运行过**：写它的开发机上没有 Docker。Dockerfile、compose 文件逐行检查过；镜像里用的引擎参数、JVM 参数和 Java 模块列表在 Windows 上跑通了演示自检，`--lan` 模式打印配对码、拒绝无令牌请求也试过。仓库推到 GitHub 后，`.github/workflows/engine-image.yml` 会构建镜像、启动它并做同样的检查。第一次在 NAS 上构建时仍可能遇到问题，欢迎反馈。

NAS（群晖、威联通、Unraid、任何装了 Docker 的 Linux）上常开一个引擎，家里所有设备连它，订阅、历史、收藏、进度都是同一份。镜像支持 x86（amd64）和 ARM（arm64）。

1. 把仓库的 `engine` 目录放到 NAS 上，在里面运行：

   ```bash
   docker compose up -d --build    # 第一次构建要几分钟：下载 Gradle 和依赖、编译引擎
   docker compose logs -f          # 看配对码
   ```

2. 日志里会出现 `配对码：123456（…前有效）`。日志里同时列出的地址是容器内部的地址，**不用管它**，其他设备用 NAS 自己的地址。
3. 在每台设备的映舟里：「源」→ 引擎地址填 `http://NAS的IP:9978` → 连接 → 输入配对码。配对码过期或用掉了：在设备上重新打开配对窗口（「源 → 局域网 → 输入配对码」），日志里会出现新的码。

说明：

- **数据**（订阅、历史、收藏、已配对的设备、jar 和转换缓存）在卷 `yingzhou-data` 里，更新镜像不会丢。想用 NAS 上的某个目录：把 compose 里的 `yingzhou-data:/data` 改成 `/volume1/docker/yingzhou:/data`，并先把这个目录的所有者改成 UID 10001（`chown -R 10001:10001 …`），引擎以这个非 root 用户运行。
- **端口**：默认 9978。要换就改 compose 里 `ports` 左边的数字（如 `"19978:9978"`），客户端填新端口。
- **自动发现**：桥接网络里 mDNS 广播出不了容器，客户端"搜索"找不到它，直接填地址即可。想要自动发现，把 compose 里的网络改成 `network_mode: host`（只在 Linux 上有效）并去掉 `ports`。
- **网页嗅探**：镜像里带了 Chromium（无沙盒模式运行，容器里没有它的沙盒需要的用户命名空间）。不需要嗅探的话，在 compose 里打开 `WITH_CHROMIUM: "false"` 再构建，镜像小一半，引擎会报告"不能嗅探"，需要嗅探的线路自动跳过。
- **名字和内存**：`TVBOX_NAME` 是其他设备看到的名字；`TVBOX_MAX_HEAP`（默认 `1g`）限制 Java 堆。
- **从 NAS 本机访问也要配对**：经 Docker 端口映射进来的请求在引擎看来来自网关地址，不算"本机"。
- **健康检查**：镜像每 30 秒访问一次 `/api/v1/info`，`docker ps` 里显示 `healthy`。
- **更新**：`git pull` 后再 `docker compose up -d --build`。

## 9. 网盘：播放自己的视频

「网盘」页可以添加三种来源，直接浏览、播放里面的视频：

| 类型 | 填什么 | 适合 |
|---|---|---|
| **AList / OpenList** | 网页地址，如 `http://192.168.1.2:5244`；可以不填账号（用访客身份），或填用户名和密码，或填 AList「设置 → 其他」里的令牌 | 阿里云盘、夸克、115、百度网盘等：先在 AList / OpenList 里挂载，映舟连 AList 就能看。映舟自己不登录这些网盘 |
| **WebDAV** | WebDAV 地址和账号。AList / OpenList 的 WebDAV 在 `/dav`，Nextcloud 在 `/remote.php/dav/files/<用户名>`，群晖、坚果云、rclone 等按各自的说明 | 任何支持 WebDAV 的网盘或 NAS |
| **本机文件夹** | 引擎所在电脑上的文件夹路径，如 `D:\Videos` | 电脑里的视频；连这台电脑引擎的电视、其他电脑也能看 |

**添加**：点右上角"添加"，选类型，填地址（名称可以不填），点"测试连接"看能不能读到，再点"添加"。"起始文件夹"可以让这个网盘只显示里面的某个文件夹（比如 `/电影`）。

**浏览**：点一个网盘进入，顶上的路径（面包屑）可以点回上层，返回键也是先回上一层。右上角可以按名称、修改时间、大小排序（再点一次倒序），文件夹总在前面；按名称排时"第2集"在"第10集"前面。视频文件可以点，旁边有同名字幕文件时会写"有字幕"；其他文件只列出来。

**播放**：点一个视频，同一个文件夹里的其他视频就是它的"选集"，播放页的上一集 / 下一集、播完自动下一集都按文件名顺序走。每个文件夹在「我的 → 观看历史」里有一条记录（来源写"网盘"），记着看到哪个文件、哪个位置：再进这个文件夹，顶上会显示"上次看到：第 2 集 12:34"，点"继续播放"接着看；在观看历史里点它也一样。点文件夹里别的视频则从头播。

**字幕**：视频旁边同名的 `.srt` / `.ass` / `.ssa` / `.vtt` 文件（如 `第1集.srt`、`第1集.zh.ass`）会随播放地址一起交给播放器。播放页显示字幕的功能在另一个版本里加入，还没有它时字幕不会显示。

**文件夹密码**（AList）：进入设了密码的文件夹会要求输入密码。输对之后引擎记住，下次不用再输，它里面的子文件夹也一样。

**谁来取文件**：

- AList 和没有账号的 WebDAV：播放器直接从网盘取（AList 的 `/d/…` 下载地址）。
- 带账号的 WebDAV、本机文件夹：由引擎取文件再给播放器，账号不会交给播放器。
- 打开"经引擎转发"后一律由引擎转给播放器。网盘只有引擎那台电脑连得上时打开它；网盘地址是 `127.0.0.1` / `localhost`（AList 和引擎装在同一台电脑上）时，其他设备播放会自动经引擎转发，不用打开。

**账号和密码存在哪**：只存在引擎那台电脑上（引擎数据目录里的 `drives.json`，明文），不会发给播放器，也不会出现在引擎回给任何设备的数据里；编辑网盘时密码框是空的，不改就留空，点框右边的按钮可以清除已保存的密码。

**其他设备**：配对过的设备（第 7 节）能看到并播放这台引擎上的所有网盘，包括本机文件夹。本机文件夹只能在引擎那台电脑上的映舟里添加或改路径，其他设备不能借此打开这台电脑上的别的文件夹。浏览本机文件夹时，指向文件夹外面的快捷方式（符号链接）不会列出来，也打不开。

**NAS / Docker**：没有界面的引擎可以在启动时加 `--drive-folder <路径>`（可以写多次）把文件夹加成网盘，比如 Docker 里挂进去的 `/media`。

## 10. 安卓手机与平板

功能和桌面版一样（引擎就在应用里），界面按手指来排。下面只写和桌面不同的地方。

### 界面

- **手机竖着拿**：六个入口在屏幕底部，「设置」在「我的」右上角的齿轮里；**平板，或者把手机横过来**：七个入口在左边一竖排（手机横屏时只有当前那个显示文字）。
- 在别的页签按系统的"返回"（返回键或从屏幕边缘往里滑）先回到首页，在首页再按才退出应用。
- 默认跟随系统的浅色 / 深色模式；想固定一种，到「设置 → 外观 → 明暗」选。
- 首页、分类、搜索、收藏的海报在手机竖屏时一行三个；详情页的海报缩小放在片名旁边，选集按钮铺满一行，手指好点。

### 播放

**竖着看**：画面在屏幕上方，下面是片名、倍速 / 弹幕 / 弹幕设置 / 字幕 / 小窗几个按钮、线路和选集，点哪集放哪集；字幕和弹幕的设置也在下面这块打开，不挡画面。

**全屏**：点画面右下角的全屏按钮，屏幕转成横向、隐藏状态栏和导航栏（竖着拍的视频转成竖向）；或者直接把手机横过来（系统的自动旋转开着时）。全屏时控制条更全：上一集 / 下一集、倍速、弹幕、字幕、选集。退出全屏：右下角的按钮，或者按"返回"——"返回"总是先退出全屏，再按才离开播放页。退出后手机回到竖屏并保持竖着，直到离开播放页。平板全屏只隐藏系统栏，退出后照常随设备旋转。

**手势**（在画面上）：

| 操作 | 作用 |
|---|---|
| 单击 | 显示 / 隐藏控制条（不会暂停） |
| 双击左边三分之一 / 右边三分之一 | 后退 / 快进 10 秒，连续双击累加 |
| 双击中间 | 暂停 / 继续 |
| 左右拖动 | 拖的时候显示要跳到的时间，松手才跳；划过整个画面宽度是三分钟（短片是整片） |
| 左半边上下拖 | 亮度（只改映舟这个窗口，离开播放页恢复系统亮度） |
| 右半边上下拖 | 音量（系统的媒体音量，和音量键是同一个） |
| 长按 | 按住时 2 倍速播放，松手恢复 |

从屏幕最边上开始的滑动留给系统（返回、下拉通知栏），不算手势。

**锁屏**：全屏或横屏时控制条左侧有一把锁，锁上后画面上的手势和"返回"都不起作用（点一下画面只会叫出锁），防止躺着看时误触；再点锁解开。

**小窗（画中画）**：视频正在播放时上滑回桌面或切到别的应用，画面会缩成一个小窗继续播，小窗里有播放 / 暂停按钮，点它可以展开回映舟；关掉小窗就暂停。也可以点控制条或竖屏操作区里的"小窗"按钮（设备支持时才有）。需要安卓 8 以上，并且没在系统设置里关掉映舟的"画中画"权限。

**其他**：播放时屏幕不会自动熄灭；没有小窗时切到后台会暂停。

### 直播

手机竖着时上面是画面，下面是正在播放的节目和「频道 / 节目单」两个页签（直播源和分组在「频道」页签里）。把手机横过来或点全屏按钮就是全屏，全屏时点一下画面叫出左侧的频道列表（上面可以换分组）和右上角的小窗、退出全屏按钮。

手势：左右滑动换到上一个 / 下一个频道（回看时是拖动跳转，长按 2 倍速），上下拖动调亮度和音量，双击暂停。小窗、屏幕常亮同点播；切到后台（没有小窗）时直播停下，回来后重新播放当前频道。

## 11. 电视盒子与遥控器（Android TV）

安卓版装在电视盒子、智能电视上时，界面换成适合在沙发上看的"遥控器模式"：字和海报更大，四周留出约 5% 的边距（很多电视会裁掉画面边缘），所有操作只用方向键、确定（OK）、返回和菜单键。装好后映舟出现在电视桌面上（带横幅图标）。

**怎么判断是不是电视**：系统报告是电视（Android TV / Google TV），或者是没有触摸屏的电视系统，就自动用遥控器模式。有的盒子不报告自己是电视，到「设置 → 外观 → 界面模式」选「电视遥控」；反过来带触摸屏的电视想用触屏界面就选「触屏」。电脑版没有这个选项，始终是桌面界面。

**焦点**：当前选中的东西有一圈珊瑚色的亮边并略微放大，从远处也看得见。方向键往哪边按焦点就往哪边走，列表会自动滚动让焦点保持在视线里；离开一个页面再回来，焦点回到原来的位置。

### 主界面

| 按键 | 作用 |
|---|---|
| ↑ / ↓ | 在左侧的入口（首页、直播、搜索、我的、源、网盘）之间移动；焦点在入口上时入口展开显示文字 |
| OK | 打开这个入口，并把焦点移进页面 |
| → | 从入口进入页面，回到上次停留的位置 |
| ← | 在页面最左边时回到左侧入口 |
| 返回 | 页面里 → 回到左侧入口；在入口上 → 回到首页；在首页 → 询问"退出映舟？" |

- **首页**：分类标签上停留片刻就切换到那个分类（和 TVBox 一样），按 ↓ 进入海报；站点名打开站点列表。
- **详情页**：进来时焦点在「播放 / 继续播放」上，↓ 依次是线路和选集。
- **搜索**：左边是字母和数字键盘，选字母后按「搜索」；键盘下面的「中文 / 语音」打开系统输入法，「手机输入」弹出二维码，在手机上输入片名（中文也行）发送过来就直接搜索（见第 3 节"手机输入"）。还没搜索时右边列出最近的搜索，按 OK 再搜一次。字母是直接拿去搜的（片名里的英文、拼音或拼音首字母），站点认不认首字母要看站点。
- **我的**：观看历史上按住 OK 或按菜单键可以删掉这一条。
- **输入框**（「源」里的订阅地址等）：焦点经过时不会弹出输入法，按 OK 才弹出；输完后按 ↓ 离开。
- **订阅**：「源 → 订阅」里按 → 走到「手机输入」，用手机扫码发送订阅地址，比用遥控器输快得多。下面的"已保存的订阅"按 OK 切换，长按 OK 或按菜单键重命名、删除。
- 下拉菜单、对话框里同样用方向键选、OK 确定、返回键关闭。

## 12. 常见问题

**网盘"测试连接"失败**
看失败的原因：写"这个地址不是 AList / OpenList"多半是地址填成了别的页面；WebDAV 提示"不支持 WebDAV（HTTP 405）"通常是地址少了 `/dav` 之类的结尾；"用户名或密码不对"就核对账号。AList 不填账号时用的是访客身份，访客被禁用的 AList 要填账号或令牌。

**网盘里的视频在其他设备上播不了，本机能播**
AList 和没有账号的 WebDAV 是由各设备的播放器自己去网盘地址取文件的。如果那个地址只有引擎那台电脑连得上（比如在另一个网段，或只写在那台电脑的 hosts 里），其他设备就播不了。到「网盘」里编辑它，打开"经引擎转发"。

**启动后提示"无法启动内置引擎"**
提示里带着引擎的最后几行输出。常见原因：安装或解压不完整（缺 `engine` 目录）、9978 端口被别的程序占用、杀毒软件拦截了 `engine\jre\bin\javaw.exe`。

**提示"订阅加载失败"**
多半是网络问题（订阅地址访问不了，或需要代理）。在浏览器里打开订阅地址能看到内容再试；也可以换一个子仓。只有第一次导入、或清过缓存之后才会卡在这里；之后引擎存有订阅的副本，地址连不上也能照常启动。

**站点更新了，这里看到的还是旧的**
站点数据会保存一会儿（见第 3 节）。点首页站点名右边的 ⟳，或详情页右上角的 ⟳，就是现在向站点要最新的。

**订阅作者更新了订阅，这里没变**
每次启动都会在后台核对一次，有变化会自动换上。不想等下次启动就到「源 → 当前配置」点"刷新"。如果那里写着"没能获取到最新的订阅"，下面一行就是原因（多半是订阅地址暂时连不上）。

**订阅里的仓库全是 404，地址里带 gh-proxy**
订阅把一个 GitHub 加速代理写死在了地址里，而那个代理失效了。确认「设置 → 网络 → GitHub 加速代理」是关闭的（默认就是），这样会绕过它直连 GitHub。如果你的网络连不上 GitHub，就打开开关，点「测速」，换一个测出来能用的代理。

**「检查更新」失败**
「更新」里写着每条路失败的原因。"直连 GitHub：连不上 / 超时"说明这台设备连不上 GitHub：到「设置 → 网络」里打开 GitHub 加速代理（点「测速」挑一个能用的），再检查一次就会经它重试；或者在「更新用的代理」里填你的 HTTP 代理。"HTTP 404"说明更新信息还没有发布（新版本发布后才有）。

**很多站点都打不开，换了订阅也一样，但别人说能用**
可能是你的网络把这些域名解析错了。到「设置 → 网络 → 安全 DNS」选一个服务商再试。没有改善就改回"关闭"。

**订阅里有 hosts，直播频道还是打不开**
`hosts`（域名重定向）目前只对引擎自己发的请求生效：取频道列表、节目单、站点数据都算，但播放器直接去取的直播流不算。靠 `hosts` 换 CDN 才能播的频道暂时还放不了。

**站点能打开，但点进去加载失败或一直转圈**
大多是站点自己失效了，换个站点试试，在安卓 TVBox 上同样会失败。如果安卓上正常、这里不行，查 [compatibility.md](compatibility.md) 里的已知缺口——最常见的是加固 jar（带 native 壳），桌面上还跑不了。

**站点标着"需要 Python"，或者打开时提示"需要 Python 3.8 或更新的版本"**
这是 Python 写的站点，见第 3 节"Python 站点"：电脑上装了 Python 会自动找到；没装就在「设置 → Python 蜘蛛」里点"下载 Python 运行时"（Windows），或者自己装一个再点刷新。装好之后不用重启，站点马上能点开。

**打开 Python 站点提示"缺少 Python 包 xxx"**
站点要用一个没装的第三方包。到「设置 → Python 蜘蛛」，点"安装常用依赖"，或者点那个包旁边的"安装"。装完马上生效。装不上时点"查看输出"能看到 pip 的原话：常见的是网络连不上 PyPI（在"镜像"里换一个国内镜像），或者这个包没有适合你这个 Python 版本的安装包（换个版本的 Python，或者用下载的运行时）。

**Python 站点提示"Python 进程退出了"**
蜘蛛把运行它的 Python 进程弄崩了（脚本有问题，或者用到的包和这个 Python 版本不兼容）。再点一次会自动重新启动 Python；一直这样就是这个站点在这台电脑上跑不了，换个站点。引擎日志里有 Python 的报错（行首是 `py:`）。

**提示"这条线路需要网页嗅探，但引擎没有可用的浏览器内核"**
嗅探要用系统里的 Edge 或 Chrome。Windows 10/11 自带 Edge；如果装在非标准位置，设环境变量 `TVBOX_BROWSER` 指向浏览器的 exe。Linux 上装 Chrome、Edge 或 Chromium，见第 1 节"Linux"。还有别的线路时播放页会先自动换过去（提示"需要网页嗅探，已切到…"），都不行才显示这句话。

**播放卡在"正在解析播放地址…"很久**
嗅探类线路要在后台打开网页抓地址，慢的要十几秒。解析失败后会自动换下一条线路；不想等可以点"选集"自己换。

**提示"所有 N 条线路都试过了，都没能播放"**
这部片在这个站点的线路都放不了，见第 4 节"线路放不了时"。可能只是一时的网络问题，点"重试"再来一轮；还不行就用「搜索」换一个站点看。

**拖动进度条后要等几秒才有画面**
跳到的位置还没缓存，要现从片源下载。进度条上浅色的部分是缓存好的，跳到那里不用等；看过的部分都会留着。如果往回拖也要等，看一下「源 → 播放缓存」的开关是不是被关掉了，或者上限是不是设得太小（放满后会删掉最久没看的部分）。个别片源不让引擎代为下载（只认播放器），这时映舟会自动退回"播放器直接取"，拖动就和没有缓存时一样。

**播放缓存占了多少磁盘，怎么清理**
「设置 → 播放缓存」里写着已用多少、上限多少，旁边有"清空缓存"。默认上限 2 GB，可以改成 512 MB 到 50 GB。缓存放在引擎所在的那台设备上（见下面"数据存在哪"）；清空或者直接删掉那个文件夹都不影响订阅和观看记录，只是再看时要重新下载。

**关掉播放缓存会怎样**
m3u8 视频改由播放器直接向片源要分片，播放器只在内存里留前后一两分钟；往回拖得远一点、或者片源慢的时候，拖动会明显变慢。一般不需要关，除非磁盘实在紧张，或者某个片源经引擎下载反而出问题。

**下载失败，写着"片源拒绝了分片（HTTP 403）"之类**
播放地址多半过期了，或者片源暂时不给。到「我的 → 下载」点 **重试**：会重新解析一次地址，已经下好的部分保留。下载途中地址过期，引擎自己会先重新解析一次，还不行才停下。

**下载显示"磁盘空间不足"或"空间不够下完这一集"**
清理一下磁盘，或者在「设置 → 离线下载」把下载位置换到空间大的盘上（新的下载才会去那里），再点重试。

**下载的文件能直接拷走吗**
下载位置里的文件是一段一段的分片，文件夹和文件名都是编号，不适合直接拿走。要拿走用「我的 → 下载」里的"导出为文件"。

**播放中间还有广告**
去广告靠订阅里的规则加一个保守的自动判断，宁可漏掉也不误删正片。没去掉说明这个站的广告规则订阅里没有。

**直播页显示"暂不支持"的直播源**
那是配置里写成 `type: 3` 却没有指定蜘蛛的直播源，还没实现。由 jar、JS 或 Python 蜘蛛给出频道列表的直播源是支持的；标着"（需要 Python）"的，见上面"站点标着'需要 Python'"。

**想知道一个订阅里到底哪些站点能用**
运行 `tools/check-configs.sh <订阅地址>`，它会把每个站点、每个直播源试一遍，生成报告 `dist/check-report.md`，并区分是引擎的问题还是站点自己失效。详见 [compatibility.md](compatibility.md) 第 8 节。

**jar 站点全部报 "cant find zipfs support"**
2026-11-13 之前打的包有这个问题（自带的 Java 运行时少了一个模块）。重新打包或换新包即可。

**其他设备连不上我电脑上的引擎**
先确认「设置 → 局域网 → 局域网共享」开着、上面列出了地址，两台设备在同一个网络（访客 Wi-Fi 通常和主网络隔离）。Windows 防火墙如果之前点了"取消"，到「Windows 安全中心 → 防火墙 → 允许应用通过防火墙」里给 `javaw.exe` 勾上"专用"。地址显示了好几个（虚拟网卡、VPN）时，用和对方同一网段的那个。

**频道没有节目单**
订阅没给节目单地址，或频道名在节目单里对不上。

**第一次打开某个 jar 站点特别慢**
要先下载 jar 并转换一次（几秒到十几秒），之后有缓存。

**数据存在哪**
订阅、历史、收藏、网盘（含账号密码，`drives.json`）：`C:\Users\<你>\.tvbox-next\engine`。jar 和转换缓存也在这个目录下，删掉会重新下载；订阅副本和站点数据在其中的 `cache\data`。海报图片在 `C:\Users\<你>\AppData\Local\Yingzhou` 下的 `posters` 目录。窗口位置、音量等界面设置在 `C:\Users\<你>\AppData\Roaming\Yingzhou`。这两处都不在安装目录里，所以升级、重装不会丢。

播放缓存（m3u8 视频的分片）在 `C:\Users\<你>\.tvbox-next\engine\cache\stream`，「设置 → 播放缓存」里也写着这个位置；它只是缓存，随时可以清空。下载默认也在这个文件夹里（"清空缓存"不会删掉它们），下载列表记在 `C:\Users\<你>\.tvbox-next\engine\downloads.json`。播放直链视频时播放器的临时缓存文件在系统临时目录的 `yingzhou-player-cache` 里，关掉视频就删除（程序异常退出留下的，下次播放时会清掉）。

Python 相关的都在 `C:\Users\<你>\.tvbox-next\engine\python`：下载的 Python 运行时（`runtime`）、给 Python 站点装的包（`packages`）、Python 蜘蛛脚本（`spiders`）。删掉整个目录不影响别的，只是要重新下载、重新安装。卸载映舟时默认保留它（和订阅、历史一样）。播放直链视频时播放器的临时缓存文件在系统临时目录的 `yingzhou-player-cache` 里，关掉视频就删除（程序异常退出留下的，下次播放时会清掉）。

**安装程序提示"检测到映舟正在运行"**
先关掉映舟的窗口再点"确定"。如果窗口已经关了还提示，在任务管理器里结束 `yingzhou.exe`。

**想给电脑上所有用户安装，或者静默安装**
用命令行运行安装程序：加 `/ALLUSERS` 装到 Program Files（需要管理员权限）；加 `/VERYSILENT` 不显示界面，可再加 `/DIR="D:\Apps\Yingzhou"` 指定位置、`/TASKS=""` 不要桌面快捷方式。
