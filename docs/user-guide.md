# 使用说明（桌面版）

> 针对 Windows 版；macOS 版操作相同，Ctrl 换成 ⌘。

## 1. 安装与启动

两种包，内容一样，任选其一：

**安装程序**（推荐）：运行 `yingzhou-windows-x64-setup.exe`，一路"下一步"。

- 只装给当前用户，不需要管理员权限，默认装到 `C:\Users\<你>\AppData\Local\Programs\Yingzhou`，可以改。
- 装完在开始菜单里有「映舟」，安装时可选是否放桌面快捷方式。
- **升级**：直接运行新版安装程序，会装到原来的位置，订阅和记录都保留。
- **卸载**：「设置 → 应用」里找到「映舟」卸载。卸载时会问要不要一并删除订阅、观看历史、收藏和设置，默认保留。
- 安装、升级、卸载前要先关掉映舟，否则会提示你关闭。
- 安装程序没有数字签名。从网上下载的安装包第一次运行时，Windows 可能弹出"Windows 已保护你的电脑"，点"更多信息 → 仍要运行"。

**绿色包**：解压 `yingzhou-windows-x64.zip` 到任意目录（路径里最好没有特殊字符），运行 `yingzhou.exe`。要"卸载"就删掉解压目录；想清掉订阅和观看记录，再删 `C:\Users\<你>\.tvbox-next` 和 `C:\Users\<你>\AppData\Roaming\Yingzhou`。

不需要另装 Java 或播放器，引擎、Java 运行时、libmpv 都在包里。启动时界面会显示"正在启动内置引擎…"，几秒后进入首页。关闭窗口时引擎一起退出。

## 2. 界面

窗口左侧（窗口窄时在底部）是五个入口：

| 入口 | 做什么 |
|---|---|
| **首页** | 选一个站点，看推荐、按分类和筛选浏览 |
| **直播** | 电视直播和节目单 |
| **搜索** | 所有站点同时搜一个片名 |
| **我的** | 观看历史、收藏 |
| **源** | 引擎连接、订阅、站点列表 |

## 3. 导入订阅

第一次打开时首页会提示"先在'源'里导入订阅"。

1. 进「源」页，在"订阅地址"里粘贴地址，点"导入"。支持 `http(s)://`、`clan://`、`file://`、带 `;pk;密钥` 后缀的加密订阅，也可以直接填本机上配置文件的路径（如 `C:\tv\my.json`）。
2. 如果是多仓订阅，会出现"选择仓库"，挑一个。条目本身又是多仓的（标着"（多仓）"），选中后会展开，它里面的条目缩进显示在下面，并自动加载其中第一个能用的。
3. 导入成功后"当前配置"显示站点、解析、直播的数量，下面列出所有站点和它们的类型。

「源」页的「网络」里有一个 **GitHub 加速代理**开关，默认关闭：这时放在 GitHub 上的订阅和文件直接从 GitHub 获取，订阅里自带的 `gh-proxy` 之类的前缀会被去掉。直连 GitHub 很慢或打不开时再打开它，并填一个你那里能用的代理地址。切换后当前订阅会立即重新加载，「当前配置」下面会显示实际访问的地址。

可以导入多个订阅并随时切换。当前用的订阅会记住，下次启动自动加载（需要联网重新拉取，会有几秒"正在加载订阅…"）。

## 4. 看片

1. 「首页」选站点 → 点海报进详情页。
2. 详情页选线路和集数，点"播放"。看过的会显示"继续播放 第 N 集 mm:ss"，旁边可以"从头播放"。点 ♡ 收藏。
3. 播放页点右下角的"选集"，侧栏里可以选集和换线路。右上角显示当前线路，以及它是怎么解析出来的（经某个解析接口、网页嗅探；直链不标）。

### 线路放不了时

一部片通常有好几条线路，其中一些可能已经失效。当前线路放不了时，播放页会自己换到下一条：

- **什么算放不了**：播放地址解析失败；播放器打不开；15 秒没有画面；播到一半断开（离片尾还远就结束了）。
- **怎么换**：按线路顺序往后找有这一集的线路，到头再从第一条接着找，每条只试一次。画面中间会提示一句，例如"「线路一」解析失败，已切到「线路二」"，右上角的线路名跟着变。
- **进度不丢**：从已经播到的位置（刚打开时是历史记录里的位置）接着播，不会回到开头。
- **全部都不行**：停在你原来选的线路上，显示最后一条线路的失败原因，下面有"重试"（按同样的顺序再来一轮）和"换线路"（打开侧栏自己挑）。
- **手动选的线路不会被换走**：你在侧栏里亲手换的线路，就算放不了也只提示，不会自动跳到别的线路；换到下一集后恢复自动。手动换线路同样从当前进度接着播。

它只能发现"放不了"。线路能播但内容不对、清晰度差或只是卡顿时，还是要自己换。所有线路都失效时也不会自动去别的站点找同一部片，用「搜索」找其他站点的同名片。

找片更快的办法是「搜索」（Ctrl+F）：输入片名回车，所有可搜索的站点同时搜，结果边到边出，顶部可以按站点过滤。

### 播放器快捷键

| 按键 / 鼠标 | 作用 |
|---|---|
| 单击画面 / 空格 | 播放、暂停 |
| 双击画面 / F | 全屏；Esc 退出全屏 |
| ← / → | 后退 / 快进 10 秒；按住 Shift 是 60 秒 |
| ↑ / ↓、滚轮 | 音量 |
| M | 静音 |
| [ / ] | 减速 / 加速 |
| N / PageDown | 下一集 |
| P / PageUp | 上一集 |
| Esc | 依次：退出全屏 → 收起侧栏 → 返回 |

音量、窗口大小和位置都会记住。

### 全局快捷键

| 按键 / 鼠标 | 作用 |
|---|---|
| Ctrl+F | 跳到搜索并聚焦输入框 |
| Alt+← / 鼠标侧键后退 | 返回上一页 |

## 5. 看直播

「直播」页从左到右是：分组 → 频道（带当前节目和进度条）→ 播放器，播放器下面是当天的节目单，正在播的那条高亮。订阅里有多个直播源时可在顶部切换。

| 按键 / 鼠标 | 作用 |
|---|---|
| ↑ / ↓ | 上一个 / 下一个频道（会跨分组） |
| ← / → | 上一条 / 下一条线路 |
| PageUp / PageDown | 上一个 / 下一个分组 |
| F / 双击画面 | 全屏；全屏时动一下鼠标或按键，频道列表会浮出来 |
| Esc | 退出全屏 |
| M / 滚轮 | 静音 / 音量 |
| 空格 | 暂停、继续 |

- 一条线路打不开，或 15 秒没有画面，会自动换下一条；全部试过都不行才提示。
- 记住上次看的频道，下次进「直播」直接播它。
- 离开「直播」页就停止播放。
- 频道列表缓存半小时，点"刷新频道"可立即重新拉取。

## 6. 我的

- **观看历史**：点一条回到详情页，从上次的位置继续。可以清空（会清掉所有设备上的记录，因为数据在引擎里）。
- **收藏**：在详情页点 ♡ 加入。

## 7. 连另一台设备上的引擎

引擎可以单独跑在一台机器上（比如常开的电脑或 NAS），其他设备的客户端连它，订阅、历史、收藏、进度就都是同一份。

1. 在那台机器上用 `--lan` 启动引擎（见 [development.md](development.md)）。
2. 在客户端「源」页把"引擎地址"改成 `http://那台机器的局域网IP:9978`，点"连接"。

> 注意：目前 `--lan` 没有密码或配对，同一局域网里的任何人都能访问。只在信任的网络里用。

## 8. 常见问题

**启动后提示"无法启动内置引擎"**
提示里带着引擎的最后几行输出。常见原因：安装或解压不完整（缺 `engine` 目录）、9978 端口被别的程序占用、杀毒软件拦截了 `engine\jre\bin\javaw.exe`。

**提示"订阅加载失败"**
多半是网络问题（订阅地址访问不了，或需要代理）。在浏览器里打开订阅地址能看到内容再试；也可以换一个子仓。

**订阅里的仓库全是 404，地址里带 gh-proxy**
订阅把一个 GitHub 加速代理写死在了地址里，而那个代理失效了。确认「源 → 网络 → GitHub 加速代理」是关闭的（默认就是），这样会绕过它直连 GitHub。如果你的网络连不上 GitHub，就打开开关并换一个能用的代理地址。

**站点能打开，但点进去加载失败或一直转圈**
大多是站点自己失效了，换个站点试试，在安卓 TVBox 上同样会失败。如果安卓上正常、这里不行，查 [compatibility.md](compatibility.md) 里的已知缺口——最常见的是加固 jar（带 native 壳）和 Python 蜘蛛，桌面上还跑不了。

**提示"这条线路需要网页嗅探，但引擎没有可用的浏览器内核"**
嗅探要用系统里的 Edge 或 Chrome。Windows 10/11 自带 Edge；如果装在非标准位置，设环境变量 `TVBOX_BROWSER` 指向浏览器的 exe。还有别的线路时播放页会先自动换过去（提示"需要网页嗅探，已切到…"），都不行才显示这句话。

**播放卡在"正在解析播放地址…"很久**
嗅探类线路要在后台打开网页抓地址，慢的要十几秒。解析失败后会自动换下一条线路；不想等可以点"选集"自己换。

**提示"所有 N 条线路都试过了，都没能播放"**
这部片在这个站点的线路都放不了，见第 4 节"线路放不了时"。可能只是一时的网络问题，点"重试"再来一轮；还不行就用「搜索」换一个站点看。

**播放中间还有广告**
去广告靠订阅里的规则加一个保守的自动判断，宁可漏掉也不误删正片。没去掉说明这个站的广告规则订阅里没有。

**直播页显示"暂不支持"的直播源**
那是配置里写成 `type: 3` 却没有指定蜘蛛的直播源，或者要用 JS / Python 蜘蛛的直播源，还没实现。用 jar 蜘蛛的直播源是支持的。

**想知道一个订阅里到底哪些站点能用**
运行 `tools/check-configs.sh <订阅地址>`，它会把每个站点、每个直播源试一遍，生成报告 `dist/check-report.md`，并区分是引擎的问题还是站点自己失效。详见 [compatibility.md](compatibility.md) 第 8 节。

**jar 站点全部报 "cant find zipfs support"**
2026-11-13 之前打的包有这个问题（自带的 Java 运行时少了一个模块）。重新打包或换新包即可。

**频道没有节目单**
订阅没给节目单地址，或频道名在节目单里对不上。

**第一次打开某个 jar 站点特别慢**
要先下载 jar 并转换一次（几秒到十几秒），之后有缓存。

**数据存在哪**
订阅、历史、收藏：`C:\Users\<你>\.tvbox-next\engine`。jar 和转换缓存也在这个目录下，删掉会重新下载。窗口位置、音量等界面设置在 `C:\Users\<你>\AppData\Roaming\Yingzhou`。这两处都不在安装目录里，所以升级、重装不会丢。

**安装程序提示"检测到映舟正在运行"**
先关掉映舟的窗口再点"确定"。如果窗口已经关了还提示，在任务管理器里结束 `yingzhou.exe`。

**想给电脑上所有用户安装，或者静默安装**
用命令行运行安装程序：加 `/ALLUSERS` 装到 Program Files（需要管理员权限）；加 `/VERYSILENT` 不显示界面，可再加 `/DIR="D:\Apps\Yingzhou"` 指定位置、`/TASKS=""` 不要桌面快捷方式。
