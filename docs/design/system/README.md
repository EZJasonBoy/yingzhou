映舟是一个看片的客户端，跑在电脑、手机、平板和电视上。它的样子来自名字和标志：**夜里的河，一条船**。界面是夜色里的水面，安静、往后退；海报和画面是亮处；船身的珊瑚色只出现在你要按的地方；三色水纹只表示「流」。

## 四条总则

1. **画面先行。** 海报和视频是页面上最亮、最大的东西。导航、按钮、文字都比它们暗、比它们小。一屏只有一件最重要的事，它最先被看到。
2. **一处暖色。** `accent`（珊瑚色）只给：主按钮、当前焦点、当前选中、当前播放的那一集。同一个区域里只出现一个 `accent` 填充。不拿它装饰。
3. **水纹只表示流。** `wave-rose`、`wave-gold`、`wave-mint` 三色只用在进度、加载、多条线路或多个来源上，按这个顺序从左到右。不做背景、不做文字、不单独拿出一色当强调色。
4. **少一步。** 能自动的不让用户选（自动换线、自动选能用的站点）；能一步做完的不分两步；电视上从首页到开始播放不超过 4 下遥控器。

## 内容与语气

- 说人话、短句、主语多半省掉。不用「您」，也不用「你」开头；需要时用「你」。
- 按钮写动作：「播放」「继续播放 第 3 集」「换线路」「导入」。不写「确定」「提交」这类空话，对话框的两个按钮写清各自的结果：「删除订阅」「保留」。
- 出错时说发生了什么、下一步是什么：「线路 1 打不开，已换到线路 2」「这个站点暂时连不上」。不出现错误码、网址和堆栈（开发者模式除外）。
- 中文和英文、数字之间留一个空格：「第 3 集」「更新至 21 集」「1080p 60 帧」。标点用全角，书名用书名号：《星河往事》。
- 不用感叹号，不用表情符号。数量和时间写具体的：「还剩 12 分钟」而不是「快看完了」。

## 交互：七条规则

样子之外，怎么用。新界面先对一遍这七条；它们的来由和例子见 [../ux-review.md](../ux-review.md)。

1. **用法只改默认值，不拿走能力。** 简单、标准、开发者三种用法只决定一件东西摆在第一层还是第二层、默认开还是关、说人话还是给细节。任何能力在任何用法里都够得着。检验：简单模式里遇到"这条线路卡"，不进设置、不输密码，在播放页就能换。
2. **一次只有一层拿焦点。** 画面、信息条、拨盘、面板、对话框，同一时刻只有最上面一层能获得焦点。方向键在这一层里走，到边上就停；关掉一层，焦点回到打开它的地方。被盖住的、隐藏的东西拿不到焦点。
3. **同一个键在同一种状态下只做一件事。** 遥控器和键盘的每个键，按"现在是哪一层"查得到一张表，表里没有"看情况"。
4. **要按的东西不挪位置。** 按钮、方向键、标签不因为内容来了或走了而移位。要显示新东西，就给它留一块固定大小的位置（空着时写明是空的），或者让它浮在上面。
5. **先叫出，再选，再进去。** 电视播放页：第一下方向键叫出拨盘并停在上次用的那一项，↑↓ 换项，←→ 直接调，OK 进去，返回一层层退。重复上一次的操作不超过两下。
6. **不让人干等。** 等待超过两秒，就显示在等什么、到了哪一步，并给一个能自己动手的选择（「选一条」「停在这里」）。能先测的先测，不要等播了才知道坏。
7. **电视上做不了的，交给手里的屏幕。** 打字、粘贴、导入导出文件、看长日志、反馈问题，在配对的手机或电脑浏览器上做；电视上只出一个二维码和结果。

**改之前数按键**：换倍速、开关弹幕、换线路、选集、看播放信息、退出播放这六件事，在流程分镜（[../../design-lab.md](../../design-lab.md)）里数要按几下，改前改后各数一次。按得更多了，就不算改好。

## 颜色

页面底色是 `bg`，往下一层是 `surface-sunk`（导航），往上依次是 `surface`（卡片、面板）、`surface-raised`（菜单、弹层、提示条）、`surface-hover`（悬停、按下、输入框）。深色主题里层次靠这几层由深到浅，不靠阴影。

- 正文 `ink`，次要信息 `ink-muted`，占位和时间戳 `ink-faint`（只在 `bg`、`surface-sunk`、`surface` 上用）。
- 珊瑚色做填充用 `accent`，上面的字用 `on-accent`（深色，不用白）；做文字和图标用 `accent-ink`；选中状态的底色用 `accent-soft` 配 `accent-ink`。
- 描边：装饰性的分隔用 `line`；表示边界的（次要按钮、输入框、开关轨道）用 `line-strong`。
- 状态：`success`、`warning`、`danger` 永远带文字或图标，不只靠颜色区分。`danger` 只在出错和删除时出现。
- 弹层后面用 `scrim` 压暗。播放器画面上的控制条永远是深色，不跟浅色主题走。
- 两个主题：**夜**（`dark`，电脑和电视默认）和 **晨**（`light`，手机平板跟随系统时用）。浅色主题里珊瑚色做文字时换成更深的 `accent-ink`，焦点框换成 `focus` 的深色值；所有文字在它说明里写的底色上都不低于 4.5:1。

## 字

- **片名和页名用宋体**（`serif`）：详情页片名 `display`，页面标题 `page-title`。这是映舟和一般应用最不一样的地方，像片头字幕。只用在这两处。
- **其余都用黑体**（`sans`）：区块标题 `headline`，海报下的片名和列表主文字 `title`，正文 `body`，次要信息 `body-sm`（配 `ink-muted`），按钮和标签 `label`，角标 `caption`。
- **数字和字母**（`latin`）：播放时间和时长用 `timecode`（等宽数字），大号数字用 `numeral`，字母标 YINGZHOU 用 `eyebrow`（大写、字距 2px）。
- 电视上所有字号乘 1.4（10 英尺距离）；手机不变。桌面最小 12px，电视最小 18px（逻辑像素）。
- 一个界面最多三种字号同时出现在主要区域里。

## 间距与布局

- 4px 网格：`space-1` 到 `space-12`。兄弟元素之间用 gap，不用各自的外边距。
- 页面左右边距：手机 `space-4`，平板 `space-6`，桌面 `space-8`，电视 `space-12`（过扫描安全区）。
- 海报墙间距：手机 `space-3`，桌面和平板 `space-5`。海报宽高比 `poster-ratio`（0.7），站点的 `style` 另有规定时按站点的。
- 可点的东西：桌面 `control-sm` / `control-md`，手机平板不低于 `control-touch`，电视 `control-tv`。
- 侧边导航宽 `rail-width`，导航入口不超过 7 个；手机底栏不超过 5 个，其余收进「我的」。

## 形状

- 海报、台标、截图 `radius-poster`；按钮、卡片、面板 `radius-md`；筛选标签、线路、选集、输入框 `radius-sm`；弹层和对话框 `radius-lg`；角标 `radius-xs`。
- **不用胶囊形**。全圆角 `radius-full` 只给开关、头像和进度条的拖动点。
- 选中不靠把整个东西涂满：标签选中是 `accent-soft` 底加 `accent-ink` 字；导航选中是图标和字变 `accent-ink`，下面一道小水纹。

## 光与层次

- 深色主题不用投影表达层次，用 `surface` 由深到浅。阴影只有两处：鼠标悬停的海报和浮层用 `shadow-lift`，电视上获得焦点的海报用 `focus` 焦点框外加 `shadow-focus-glow`。
- 浅色主题里 `surface` 和 `surface-raised` 都是白色，靠 `line` 和 `shadow-lift` 区分。

## 焦点与状态

- **焦点**：键盘和遥控器的当前焦点是 3px 的 `focus` 实线，离元素 2px；电视上的海报再放大到 1.06 并加 `shadow-focus-glow`。所有能获得焦点的东西都有焦点样式，没有例外。
- **悬停**：底色换成 `surface-hover`；海报上浮 2px 并加 `shadow-lift`。
- **按下**：缩到 0.98。
- **选中**：见「形状」。
- **不可用**：整体 38% 不透明度，不再响应悬停。

## 动效

悬停 120ms；焦点移动、选中 200ms，减速曲线；页面、弹层 320ms。焦点框跟着焦点滑过去，不闪。系统设置了减少动态效果时，只保留透明度变化。水纹只在加载时缓慢流动，播放时静止。

## 图标

用 Material Symbols 的圆角风格（Rounded），线宽 400，桌面 22px、电视 28px，不混用描边和填充两套。图标和文字并排时间距 `space-1` 或 `space-2`。品牌只有一个标志：船（`assets/Logos`），帆是播放键；不把它改色、拉伸或拆开用。侧边导航顶部放小号标志，不放通用的电视图标。

## 四种设备

- **电脑**：鼠标键盘是一等公民。悬停显示次要操作，快捷键覆盖常用操作（空格、F、方向键、Ctrl+F）。默认 **夜** 主题。
- **手机**：底栏导航，竖屏海报三列；播放页靠手势（双击快进、上下滑亮度音量、长按倍速）。主题跟随系统。
- **平板**：侧边导航加更宽的海报墙；其余同手机。
- **电视**：只用方向键、OK、返回、菜单。焦点永远看得见、不会丢，返回键一层层退回首页。字号乘 1.4，边距 `space-12`。默认 **夜** 主题。

## 用在哪里

- **应用**：`docs/design/tokens.json` 生成 `client/lib/ui/yz_tokens.dart`，主题（`client/lib/ui/theme.dart`）只用这些 token。
- **原型**：[../prototypes](../prototypes/README.md) 里三种用法、电视播放页的拨盘和网页控制台的画板都只用这套颜色、字和组件，可以照着搭新的界面。
- **宣传**：`components/` 里每个组件有说明和预览页（`preview.html`），`components/bundle.css` 是全部 token 和组件样式，网页、海报、作品集可以直接引用；`assets/` 里是标志和演示用的图片（海报和画面都是虚构的）。
