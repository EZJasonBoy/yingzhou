# Notice

浮在页面上的一句话：刚发生了什么、要不要撤回。

**用在**：自动换线、下载完成、订阅导入成功、操作失败。

**使用方提供**：一句话、类型（成功 / 提醒 / 出错 / 进行中）、可选的一个操作（「换回去」「查看」）。

**规则**
- `surface-raised` 底、`shadow-lift`、圆角 `radius-md`，正文 `body`。
- 句子说发生了什么和下一步，不出现错误码：「这条线路打不开，已换到下一条」。
- 图标表明类型：成功 `success` 对勾、提醒 `warning`、出错 `danger`、进行中 `wave-gold`。颜色永远配图标，不单独靠颜色。
- 最多一个操作，用 `accent-ink` 文字按钮放右边。4 秒后自己消失；有操作的 6 秒。
- 播放器里的提示用同样的形状，放在画面左上角，不挡字幕。

**在 Flutter 里**：`SnackBar` 的主题；播放器里的提示在播放页里。
