# Tabs

页面内的分类切换：推荐、电影、剧集、动漫、纪录片。

**用在**：首页的站点分类、「我的」里的历史 / 收藏 / 下载。

**使用方提供**：标签名列表、当前是哪一个、切换时做什么。

**规则**
- 页面标题在上（`page-title`，宋体），标签在下。
- 未选中 `body` 配 `ink-muted`；选中变 `ink`、加粗，下面一道三色小水纹，和 NavRail 用同一个记号。
- 标签之间 `space-6`；放不下时横向滚动，不换行，不缩小字号。
- 电视上方向键左右切换，焦点框套在标签文字外。

**在 Flutter 里**：首页的 `TabBar`，水纹指示由 `WaveTabIndicator` 画。
