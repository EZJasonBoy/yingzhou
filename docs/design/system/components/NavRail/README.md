# NavRail

电脑和平板左侧的主导航：顶部是船的标志，下面是不超过 7 个入口。

**用在**：桌面窗口和平板（手机竖屏换成底栏，电视换成大号的左侧导航，规则相同）。

**使用方提供**：入口列表（图标、名字）、当前是哪一个、点按时切到哪一页。

**规则**
- 底色 `surface-sunk`，宽 `rail-width`。顶部放小号标志（`assets/Logos/yingzhou-logo-small.svg`），不放通用的电视图标。
- 入口：图标在上、名字在下，`ink-muted`；悬停 `surface-hover`。
- 当前入口：图标改填充、图标和名字变 `accent-ink`，名字下面一道三色小水纹。**不用胶囊形的高亮底。**
- 入口不超过 7 个；多出来的放进「设置」或「我的」。

**在 Flutter 里**：主界面的 `NavigationRail`（待按本规范重做：标志和水纹指示）。
