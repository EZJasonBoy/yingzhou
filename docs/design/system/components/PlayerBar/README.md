# PlayerBar

播放器底部的控制条：进度、时间、常用操作。不论浅色深色，它都在画面上的深色渐变里。

**用在**：点播和直播回看的播放页（电脑、手机横屏、平板、电视）。

**使用方提供**：已播放位置、已缓冲位置、总时长、播放 / 暂停状态、各按钮的动作。

**规则**
- 进度条是映舟的标志性部件：**已播放的部分是一道 `accent` 的细水纹**，拖动点是 `radius-full` 的圆；已缓冲的部分是三色水纹的淡色版，表示「流」进来的部分；未缓冲是半透明的直线。
- 时间用 `timecode`（等宽数字），「已播 / 总长」。
- 按钮只放常用的：播放暂停、下一集、音量、倍速、弹幕、字幕、选集、全屏。其余收进菜单。
- 不动鼠标、不按键 3 秒后整条淡出；任何操作让它回来。电视上按 ↓ 唤出。

**在 Flutter 里**：播放页的控制条和进度条（进度条待按本规范重做）。
