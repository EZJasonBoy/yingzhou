# SettingsRow

设置里的一行：名字、一句说明、右边的开关或当前值。

**用在**：「设置」页的每一项；同类的几行放进一个分组卡片。

**使用方提供**：名字、说明（可空）、右侧是开关（开 / 关）还是一个值（点按进下一层），点按时做什么。

**规则**
- 分组卡片 `surface` 底、圆角 `radius-md`；组名 `body-sm` 加粗配 `ink-muted`。
- 行高不低于 `control-touch`；名字 `title`，说明 `body-sm` 配 `ink-muted`；行之间 `line` 分隔。
- 开关：开是 `accent` 底加 `on-accent` 的圆点；关是 `line-strong` 描边。
- 说明写这一项会带来什么，尤其是会把数据交给第三方的：「打开后向 GitHub 查询新版本，最多一天一次」。
- 任何设置都不超过三层。

**在 Flutter 里**：「设置」页和各设置分页的列表项。
