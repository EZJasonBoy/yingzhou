# Button

按下去会做一件事的东西。三种：主按钮、次要按钮、文字按钮，加一种只有图标的。

**用在**：详情页的「继续播放」「从头播放」、对话框、设置里的操作。

**使用方提供**：动作的文字（写动作，不写「确定」）、可选的图标、可选的附加信息（如续播位置）、是否可用、点按时做什么。

**规则**
- **主按钮**：`accent` 底、`on-accent` 字、加粗。一屏一个，放在最先看到的地方。
- **次要按钮**：透明底、`line-strong` 描边、`ink` 字。
- **文字按钮**：`accent-ink` 字，没有底和边，用在不重要的操作上（收藏、全部）。
- **图标按钮**：`surface-hover` 底的方块，必须有文字提示（悬停提示或无障碍标签）。
- 高 `control-md`，手机平板 `control-touch`，电视 `control-tv`；圆角 `radius-md`。
- 焦点：`focus` 3px 实线外扩 2px。不可用：38% 不透明度。
- 附加信息用 `timecode` 字体：「继续播放 第 3 集 12:30」。

**在 Flutter 里**：`FilledButton`（主）、`OutlinedButton`（次要）、`TextButton`（文字）、`IconButton` 的主题。
