# WaveLoader

三个按水纹颜色排列的小圆点上下起伏：东西正在流进来。

**用在**：加载片单、等待解析、搜索还有站点没回来。取代通用的转圈。

**使用方提供**：可选的一句说明（「还在等 2 个站点」）。

**规则**
- 三点依次 `wave-rose`、`wave-gold`、`wave-mint`，6px，间距 6px，起伏 8px，周期 1.2 秒。
- 后面可以跟一句 `body-sm` 的说明，配 `ink-muted`，说还在等什么。
- 系统要求减少动态效果时，三点静止。
- 海报未加载不用它（用 `poster-empty` 占位）；整页加载超过 1 秒才出现。

**在 Flutter 里**：待新增，替换各页面的 `CircularProgressIndicator`。
