# 设计

映舟的界面和交互怎么定、怎么做、怎么验证。

| 目录 / 文件 | 是什么 |
|---|---|
| [system/](system/README.md) | 设计系统「夜航」：总则、语气、颜色、字、间距、形状、焦点、动效、图标、四种设备，十个组件各有说明和预览页 |
| [tokens.json](tokens.json) | 设计系统的唯一来源：两个主题的颜色、字号、间距、圆角、阴影、尺寸。改了运行 `node tools/design/gen-tokens.mjs` |
| [prototypes/](prototypes/README.md) | 三种用法（简单、标准、开发者）的界面原型，图片、可点的网页和画布源文件 |
| [../design-lab.md](../design-lab.md) | 工作流：设计台（四种设备并排的真实应用）、流程分镜（数步数）、界面巡览（三种尺寸的截图） |

一个新界面的顺序：先写清楚任务和步数，在原型里试，再写进代码，最后在设计台和流程分镜里验证。
